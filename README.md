# 🎓 中大圈 NCU Loop（MVP）

**找得回物品，幫得上同學，逛得到活動**：三個校園生活入口，共用一條安全的站內私訊通道。
Microsoft × NCU AI Innovation Demo Day｜AI for Better Campus & Life

> **v3 新增：🎯 松果任務＋🛍️ 松果商店**（簽到、金松果點、每日／每週任務、39 件衣服含中大系列）。
> **v2 新增：🗺️ 松鼠地圖**。每位使用者是一隻中大松鼠，在校園示意地圖上跑來跑去，看各區域的失物、任務、活動；
> 搭配「🌰 松果」感謝點數、徽章與排行榜。中央大學以「松」為精神象徵，所以積分就叫松果。
>
> 主線（依助教建議）：**失物招領＋安全私訊**。任務互助用來證明私訊通道可以共用；活動資訊是精簡版。
> 所有資料都是**示範資料（虛構）**。平台**不經手任何金錢**。

## 快速開始

```bash
pip install -r requirements.txt
python seed_data.py          # 產生示範資料（Demo 前跑一次 = 重設）
python tests/test_core.py    # 跑自動測試，應顯示「全部通過」
streamlit run app.py         # 找不到指令就改用：python -m streamlit run app.py
```

示範帳號：`小宇`、`小晴`、`小安`、`小凱`、`阿明`、`小美`，密碼都是 `demo1234`。
**不需要安裝新套件**：地圖是用 Streamlit 內建的自訂元件功能做的（純 HTML＋JavaScript）。
要測私訊，請開**兩個不同的瀏覽器**（例如 Chrome＋Edge，或一般視窗＋無痕視窗），各登入一個帳號。

## 🗺️ 松鼠地圖

| 操作 | 效果 |
|---|---|
| 點建築物或徽章 | 你的松鼠一跳一跳走過去，右邊面板列出那裡的失物／任務／活動，可以直接聯絡、接單 |
| 點一下地圖後按方向鍵／WASD | 自由走路，停在建築物附近會自動進去 |
| 滑鼠移到區域上 | 提示框：各類數量、前幾筆標題、誰在這裡、有沒有快截止的任務 |
| 上方圖層按鈕 | 開關「遺失／拾獲／任務／活動／其他松鼠」 |
| ＋／－／⟲（或 Ctrl＋滾輪、拖曳） | 縮放、平移、回到全圖 |
| 上方搜尋框 | 符合的區域會發亮 |

**避免雜亂的做法**：參考其他校園地圖 App（把圖釘整合到建築物層級、把重疊的圖釘拆開）：
1. 一個區域只有**一個徽章**（數字＋小色點），不是一筆一個圖釘
2. 只有「24 小時內新刊登」有紅色波紋、「3 小時內截止」有 ⏰，其餘都是靜態的
3. 細節放在滑鼠提示框和右側面板；同一區最多畫 6 隻松鼠，位置錯開不重疊
4. 松樹會避開道路與建築物

**調整地圖**：`campus_map.py` 的 `ZONES` 是示意座標（畫布 1000×640）。請全組依照真實校園的相對位置修改 x、y，
並在 `aliases` 加上同學常用的地點說法（例如「工五」「綜教」），刊登時填的地點才對得到區域。

## 🌰 松果任務系統（v3）

| 來源 | 松果 | 說明 |
|---|---|---|
| 📅 每日簽到 | 5～10，第 7 天再 +20 | 連續越多天越多（加成上限 +5）；每天第一次進網站會跳出簽到視窗 |
| ✨ 今日金松果點 | 每顆 +3（一天 3 顆） | 每天 3 個區域出現金松果，大家看到的位置一樣，松鼠走過去就撿到 |
| 🐾 新足跡 | +1（每天最多 5） | 今天第一次走到某個區域 |
| ☀️ 每日任務 | 2～10 | 固定 2 個（散步 3 區、撿齊金松果）＋題庫每天輪替 3 個 |
| 📆 每週任務 | 20～30 | 簽到 5 天、走過 8 區、完成別人的任務、幫人找回失物 |
| 🤝 完成別人的任務 | +10 | 由**任務發布者**按「完成」 |
| 💎 幫人找回失物 | +20 | 由**失主**或**認領者**確認 |
| 🏅 解鎖徽章 | 5～50（一次性） | 在任務中心領取 |

**防灌分**：「刊登」本身不給松果；幫助別人的大額松果一定由被幫助的人確認；每個任務每天／每週只能領一次（`ref` 去重複）；探索與簽到加成都有上限。
排行榜用「累計賺到」的松果，買東西不會讓排名下降。

## 🛍️ 松果商店

- **5 個部位、39 件衣服**＋**10 種毛色**（5 種免費、5 種要用松果買），分「普通／稀有／傳說」三種稀有度
- **👀 試衣間**：商店最上方有一隻放大的「你的松鼠」。在商品按「試穿」就會穿上去，可以同時試帽子＋上衣＋手持…看整套效果，旁邊列出總價，一次「買下這一套」
- **🛒 購買確認視窗**：按「買」會跳出「現在的你 ➜ 換上之後」的對照圖、價格明細、購買前後的松果數，按「確認」才扣松果；松果不夠時會提示去哪裡賺
- 每張商品卡的小圖也是「你的松鼠穿上這件」的樣子；松果不夠時整套一件都不會買（不會買一半）
- **⏰ 每日特價**：每天一件商品打 8 折
- **🎓 中大系列**（9 件）：NCU 棒球帽、中大湖鴨鴨帽、NCU 字樣T恤、中大帽T、NCU 系際盃球衣、松濤圍巾、中大湖鴨鴨泳圈、NCU 加油小旗、NCU 帆布袋。
  全部是團隊原創設計，只用「NCU」「中大」字樣和松樹、中大湖鴨子等元素，**沒有使用學校官方校徽**；若要放校徽或做成實體周邊，需先取得學校授權
- 松果**只能換虛擬造型**，不能換錢或實體商品
- 新增衣服：在 `wardrobe.py` 的 `ITEMS` 加一筆（id、名稱、部位、價格、稀有度、SVG），畫布 64×64，座標說明寫在檔案開頭

**隱私**：地圖上的松鼠位置是「你在網站上逛到哪裡」，不是 GPS；「我的松鼠」頁可以開隱身、也可以不上排行榜。

## 配對評分表（`lostfound.py`）

| 項目 | 分數 |
|---|---|
| 前提 | 一筆「遺失」＋一筆「拾獲」，都在「尋找中」，不同刊登者 |
| 類別相同 | +3 |
| 地點相同 | +2 |
| 日期相差 ≤ 1 天／2–3 天 | +2／+1（相差 > 7 天直接排除） |
| 關鍵字重疊 | 每個 +1，最多 +3 |
| **門檻** | 總分 ≥ 4 |

**手算案例**：小宇遺失「黑色保溫水壺」（雨傘水壺／圖書館／昨天／黑色、保溫水壺、水壺），小晴拾獲「黑色保溫水壺」（雨傘水壺／圖書館／昨天／黑色、水壺、貼紙）
→ 類別 +3、地點 +2、同一天 +2、關鍵字 3 個 +3 → **10 分**（這個例子寫在 `tests/test_core.py`）。

**AI 的角色**：規則先找出最多 5 個候選，**AI 再依描述語意重新排序並寫理由**。AI 回傳的 id 必須都在候選裡，出現不存在的 id 就整份作廢、改用規則版。所以「規則版 vs AI 版的前 3 名」可以拿來比較。

## AI 能力層

| 編號 | 功能 | AI 做什麼 | 規則保底 |
|---|---|---|---|
| AI-1 | 一句話發布 | 一句話 → 表單欄位、提醒缺漏 | 物品詞／顏色／地點清單＋日期詞（今天、昨天、週五、11/18…） |
| AI-2 | 配對與理由 | 在規則候選中**重新排序**＋一句理由 | 評分表＋模板理由 |
| AI-3 | 隱私守門 | （以規則為主） | 偵測學號、手機、Email、身分證；公開內容自動遮蔽，私訊先提醒再由使用者決定 |
| AI-4 | 面交安全助手 | 從**白名單**挑地點、寫提醒、3 則快速回覆 | 固定白名單＋通用提醒 |
| AI-5 | 認領驗證問題 | 產生「只有失主答得出」的問題 | 依類別的模板 |
| AI-6 | 任務規範檢查 | 只能把「通過」**加嚴**成「提醒」 | 關鍵字規則；**「禁止」只由規則判定** |
| AI-7 | 活動推薦 | 只能從**現有活動**挑最多 3 個 | 興趣與標籤重疊計分 |
| 新增 | 私訊防詐提醒 | — | 匯款、驗證碼、加賴、外部連結等關鍵字，送出前提醒 |

畫面上每個結果都標示「🤖 AI 建議」或「📏 規則建議」。
**決賽 Demo 請用 `USE_AI=true`**，讓評審看到 AI 標籤；規則版當備案（網路斷掉時自動切換，畫面不會報錯）。

## 安全設計（回應助教「獨立沙盒、詐騙、資安」）

- **沙盒**：每個私訊是獨立檔案，只有兩位參與者能讀寫，畫面顯示前每次都檢查。
- **不公開聯絡方式**：資料裡沒有聯絡欄位；公開內容自動遮蔽個資。
- **防詐**：私訊送出前檢查詐騙關鍵字；系統訊息固定提醒不要先付錢、不要提供驗證碼。
- **檢舉＋封鎖**：檢舉只記錄原因與討論串 id（`data/reports.json`）；封鎖後雙方都不能再傳訊息。
- **認領驗證**：答案只有拾獲者看得到、**不送給 AI**，由拾獲者人工判斷。
- **證件類**：提示同時交由校內既有失物招領管道。
- **密碼**：PBKDF2-SHA256 加鹽雜湊（標準函式庫 `hashlib`），至少 6 碼。
- **面交**：只能從安全地點白名單選。

## 已知限制（誠實聲明）

- 私訊是**準即時（約 3 秒更新）**，用 `st.fragment(run_every=3)` 輪詢，不是 WebSocket。
- JSON 檔不是資料庫：兩人在同一瞬間寫同一個討論串仍可能遺失一則；目前的做法是「每個討論串一個檔＋寫入前重新讀檔＋原子寫入」來縮小風險。**Demo 採單人依序操作**。
- 登入是示範等級，不是正式安全方案；管理者可以直接讀 JSON。
- **部署**：Demo 在本機執行。如果部署到 Streamlit Community Cloud，重新啟動時 `data/` 會被重設（等於跑一次 `seed_data.py`），正式版要改用資料庫。
